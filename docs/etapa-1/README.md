# Etapa 1 — Documentação técnica

## Projeto

**StockFlow** é um sistema de gerenciamento de estoque e vendas voltado a pequenas e médias empresas.

O projeto foi concebido para centralizar informações de produtos, fornecedores, clientes e movimentações, permitindo acompanhar entradas e saídas, saldo de estoque, vendas e informações gerenciais.

## Usuários

- **Administrador:** acesso às funções administrativas e gerenciamento geral.
- **Estoquista:** responsável pelas operações de estoque.
- **Vendedor:** responsável pelas operações relacionadas às vendas.

## Escopo funcional

A documentação inicial prevê cadastro e gerenciamento de produtos, fornecedores, clientes e usuários; registro de entradas e saídas; consulta de estoque; vendas; relatórios; login e controle de permissões.

## Requisitos não funcionais

A etapa inicial considera requisitos relacionados a acesso, usabilidade da interface, backup, desempenho e compatibilidade.
